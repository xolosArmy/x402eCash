Gate contract

One live request. Then stop.

The tool accepts an empty object, makes one uncached HTTPS request, requires HTTP 402, decodes and strictly validates PAYMENT-REQUIRED, and reports the experimental requirement without sending payment data.

Live 402 contract

The browser requests the public x402-XEC demo endpoint and accepts only its exact reviewed HTTP 402 header contract.

03

Validate and stop

Missing or malformed protocol data fails visibly. A valid response reports 100 XEC as required, records that no payment occurred, and stops.

Project boundary: x402eCash remains the static public laboratory and evidence portal. x402-XEC remains the separate protocol implementation. This experiment does not turn the portal into a payment backend.
