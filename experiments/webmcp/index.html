Gate contract

One live request. One human decision. Then stop.

The tool accepts an empty object, makes one uncached HTTPS request, requires HTTP 402, strictly validates PAYMENT-REQUIRED, and pauses until the human approves or rejects. Neither decision sends payment data.

01

Discovery

The page registers one imperative WebMCP tool when the browser exposes the required API.

02

Live 402 contract

The browser requests the public x402-XEC demo endpoint and accepts only its exact reviewed HTTP 402 header contract.

03

Human boundary

Only a valid 100 XEC requirement reveals the decision controls. Approval authorizes proceeding toward a future signing stage; rejection stops the flow. Neither action signs or pays.

Project boundary: x402eCash remains the static public laboratory and evidence portal. x402-XEC remains the separate protocol implementation. This experiment does not turn the portal into a payment backend.

Gate H3A adds explicit human authorization after live HTTP 402 validation. It does not demonstrate an XEC payment, signature, transaction, settlement, or resource unlock.
